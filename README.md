🔒 Политика конфиденциальности
Приложение: Muzeylar UZ
Дата последнего обновления: 02.01.26
1. Общие положения
Приложение Muzeylar UZ уважает конфиденциальность пользователей и не собирает, не хранит и не передаёт персональные данные пользователей.
Используя приложение, вы соглашаетесь с настоящей Политикой конфиденциальности.
2. Сбор и использование информации
Приложение не собирает следующие данные:
персональные данные (имя, телефон, email и т.д.)
данные о местоположении
данные об устройстве
идентификаторы пользователей
Вся информация о музеях (описания, адреса, фотографии) хранится локально на устройстве пользователя и используется исключительно для отображения контента внутри приложения.
3. Хранение данных
Все данные находятся локально на устройстве пользователя
Приложение не использует серверы
Приложение не передает данные третьим лицам
4. Фотографии и медиа-контент
Все изображения и медиа-файлы используются исключительно в информационных целях для представления музеев Узбекистана и не связаны с персональными данными пользователей.
5. Сторонние сервисы
Приложение не использует сторонние сервисы:
Google Analytics
Firebase
рекламные SDK
сторонние API
6. Безопасность
Поскольку приложение не собирает и не обрабатывает персональные данные, риски утечки информации отсутствуют.
7. Изменения в политике
Разработчик оставляет за собой право обновлять данную Политику конфиденциальности. Актуальная версия всегда доступна по той же ссылке.
